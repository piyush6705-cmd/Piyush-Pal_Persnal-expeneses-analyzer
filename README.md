# Personal Expense Analyzer

## About the Project

The Personal Expense Analyzer is a Python-based project that analyzes personal expenses using NumPy and Pandas. It helps users understand their spending habits through data analysis.

## Objectives

- Calculate total and average expenses.
- Find maximum and minimum expenses.
- Analyse expenses category-wise.
- Filter and sort transactions.
- Identify the category with the highest spending.
- Generate a final CSV report.

## Technologies Used

- Python
- NumPy
- Pandas
- Jupyter Notebook
- CSV Dataset

## Dataset Information

The dataset contains the following columns:

- **Date:** Date of the transaction.
- **Category:** Expense category.
- **Amount:** Money spent.

## Key Features

1. Dataset loading and exploration.
2. Missing value and duplicate checking.
3. Numerical calculations using NumPy.
4. Creating new columns.
5. Filtering and sorting expense records.
6. Category-wise expense analysis.
7. Exporting the final report as a CSV file.

## Project Results

- Total Transactions: 40
- Total Expenses: ₹6,790
- Average Expense: ₹169.75
- Maximum Expense: ₹500
- Minimum Expense: ₹30
- Highest Spending Category: Books
- Total Books Expenses: ₹1,780

## How to Run the Project

1. Download or clone this repository.
2. Install Python.
3. Install the required libraries:
   `pip install numpy pandas jupyter`
4. Keep the notebook and dataset CSV file in the same folder.
5. Open Jupyter Notebook.
6. Run all cells.

## Files Included

- `Personal_Expense_Analyzer.ipynb` – Project notebook.
- `Student_18_dataset.csv` – Original dataset.
- `Student_18_expense_analysis_GitHub.csv` – Final analysis report.

## Conclusion

This project demonstrates how Python, NumPy and Pandas can be used to analyse expense data, identify spending patterns and generate useful reports.
